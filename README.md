# Neptun NFT Profile Parser

Парсер NFT **только по профилю**:
- у человека есть NFT в профиле
- **0 лотов на маркете**

## Установка
```bash
pip install -r requirements.txt
python bot.py
```

## Как пользоваться
1. `/start` → `/admin` → авторизация Telethon (номер + код)
2. «Собрать базу» — лёгкий сбор юзеров с маркета (кандидаты)
3. «Поиск по профилю» / «Только девушки»

## Важно
- Запускай **один** процесс (иначе Telegram снесёт сессию)
- Доступ только у владельца `7186944876`
- Между запросами пауза `TG_REQUEST_GAP` (по умолчанию 2 сек)
- Сессия: `telethon_auth.string`
